# Systems alignment

The short-form map for #784 records design, current evidence and proposed integration. The full system pages, Appendix A inventory, build plan and owner-question cards are pending.

The 21.11 brief asks for an integrated plan that connects each system’s place, level, shop, challenge and materials. The recorded basket ruling would retire the basket as a gathering tool (2.4). The exploration ruling would let players find recipe pages without fighting, with the gate-rubble proposal in 1.4 and the weapon rollout in 9.2.

## How to read this page

Each numbered row carries the design, comparison reading, code baseline, gap, proposal, integration, plan ID and open decision. A dash marks a field with no claim. Comparison readings point to the repository’s existing surveys. Plan IDs are placeholders for §3.

Current code and content citations are pinned to local `origin/develop` at `d956c00e`. For example, `kernel/src/step.ts:1114-1129` means those lines at that ref. Proposal references point to the design sources or rule they use.

Written 2026-11-02 by an outside developer for the owner; a map of the sources, nothing is built with it. It reads develop ebd425b2c (02.11) and the open gear pull request #609, and maps the 158 materials of the materials count ([MATERIALS_COUNT.md](MATERIALS_COUNT.md), the companion page) and nothing else. Every number on it is computed from one data set that covers each counted material once; the data set is not committed, this page is the record.

**Totals.** 158 materials = 17 built + 127 planned in landed pages + 14 planned only in #609 (raw 97, processed 61). Coverage check of this page: 158 of 158 counted materials have exactly one row; missing 0, extra 0, duplicates 0.

**Measured since the count.** The count was re-checked on 02.11 against develop ebd425b2c and the #609 head a8e4915d1 and holds (158 = 17 + 127 + 14); what moved is anchors, not materials, listed under "Re-checked on 02.11" in [MATERIALS_COUNT.md](MATERIALS_COUNT.md). The one delta this page applies: bronze bar is cited as QUARRYING 13 (#609) alone, the word "bar" left WEAPONS 5.1 (#609). The keystone's kind sits at content/core/resources/keystone.json:13 (the item), the node of the same id at :5.

## 1. How to read this page

1. **What a row is.** One row per counted material: one distinct thing a player holds, grades folded into one, a raw and a cured form two rows (the counting rules of MATERIALS_COUNT). The 158 are the same list, by the same names; nothing here adds to or takes from the count. Meats, baits, fuel, dyes and gems are borderline inputs, outside the 158; section 6 maps the ones this page reached.
2. **The states.** BUILT: the step runs on develop today (code and content). PLANNED (landed): a page on develop describes it, nothing runs it. PLANNED (#609): only the open gear pull request's pages describe it. HOLE: no page gives it a source, a recipe or a station. SUGGESTED: a reading this page offers to close a hole; it is not planned by anyone and is kept apart in section 5. In the step column the marks are [B], [P], [P609], [H]. A material's own state is its count status, or HOLE when a hole sits on its path; '; SUGGESTED' is added when a suggestion exists.
3. **The columns.** Tier is the count's tier (? when no page gives one). Status is the count's word (built, planned-landed, planned-open-pr). Source is where the raw thing comes from. Steps run world to product, each as verb (tool; skill; station) [state]; a tool spent as an input (stone flakes, herb, the branch as fuel) is written as such, because TOOL_KINDS is closed (schema/src/index.ts:53). Uses is what takes the material. Len is the chain length, the number of steps from the world to this material (0: no path at all). Anchors are path:line on develop ebd425b2c or 'PAGE section (#609)' for the open pages.
4. **Shared steps are drawn once.** Section 2 gives one diagram per family with the animals or nodes as inputs; the per-animal chains beneath it are this page's lines. The findings under each family are the readings of the pass that mapped it.
5. **One data set.** Every row, chain and statistic is printed from one data set that matches each counted material by id or name against the count; a mismatch stops the print with a list of missing and extra names, so the 158 here are the count's 158 (coverage: 158 of 158, missing 0, extra 0, duplicates 0).
6. **Checked.** Two independent readers verified the rows and anchors against develop ebd425b2c and the #609 head a8e4915d1 on 02.11; the tables carry their corrections.

# Archive

Retired content, kept for reference and never loaded: the game reads only `content/`.

- `content/core/starters/`: the three starters (explorer, forager, digger), retired on 2026-10-22 when the races replaced them (DECISIONS.md). Their wake places live on as the wake pockets in `content/core/pockets/`; an old save or a logged game that names a starter is read through the kernel's `LEGACY_STARTERS`.

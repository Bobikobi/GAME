# Extension template

A working extension: one fruit bush for the empty glade west of the river, a plum that drops
below a bush left full (a reaction), and a quest.

1. Copy this folder to `content/extensions/<your-handle>/`.
2. Replace `your-handle` with your GitHub handle, in lowercase, in every file.
3. Run `pnpm check`.

The full walk-through is [docs/creators/README.md](../../docs/creators/README.md).

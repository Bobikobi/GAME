# Extension template

A working townsperson (Wren the mender, at the trainers' stall), plus examples for later: a fruit,
a reaction and a quest. Every resource slot is filled today, so the fruit keeps its old glade slot
only as a reference; use it when an open call names a new resource slot.

1. Copy this folder to `content/extensions/<your-handle>/`.
2. Replace `your-handle` with your GitHub handle, in lowercase, in every file.
3. Run `pnpm check`.

The full walk-through is [docs/creators/README.md](../../docs/creators/README.md).

## Why

A project that many people write in needs one thing to be sure of: that it may keep publishing, fixing and moving what they gave it, without asking each person again. This agreement says so in writing, for your protection and for the Project's.

## 1. Definitions

- **Contribution** means any original work of authorship, including a change or addition to an existing work, that You intentionally submit to the Project for inclusion in the game, its content, its art or its documentation (the **Work**). "Submitted" means any electronic, verbal or written communication sent to the Project or its maintainers, in a pull request, an issue or a comment on one, but not a communication that You conspicuously mark "Not a Contribution".
- A contribution made with an AI tool is Yours when You direct it, check it and list the tool in `ai_tools` as the guide asks; sections 4 and 5 apply to it as to anything else.

## How you sign

The CLA bot comments on your first pull request. Post this one comment, as it is written:

> I have read the CLA Document and I hereby sign the CLA

The bot records your GitHub account, the comment and the pull request in the file `signatures/v1/cla.json` on the branch `cla-signatures` of this repository. That record is public, as the pull request is. Signing a later version of this agreement, if there is one, is asked again the same way.
